# Franka FR3真机抓放结果

FLASH自主抓放最终为**40/50（80%）**，采用操作者提供的50次尝试最终计数。运动与时延统计来自所提供日志报告中的25条执行记录、840个预测请求。

## 指标

| 指标 | 数值 |
| --- | --- |
| 自主抓放成功率 | **80%（40/50）** |
| 七关节采样跟踪MAE | **0.6002 ± 0.0361°** |
| 七关节时间加权跟踪MAE | 0.5996 ± 0.0365° |
| 控制器记录区间 | 17.8389 ± 2.6105 s |
| 实际连续换段次数 | 31.5600 ± 4.8139 |
| 服务端预测与解码 | 均值23.434 ms，P50 25.468 ms，P95 26.402 ms |
| 观测到候选就绪 | 均值307.542 ms，P95 426.161 ms |

±表示25条试次指标的样本标准差；时延分位数由合并请求统计。完整数值、样本量和来源哈希见[summary.json](summary.json)。

## 统计口径

- 跟踪MAE比较执行参考与实测关节位置，基于约25 Hz及事件触发状态采样，区别于离线模型预测误差及1 kHz完整轨迹统计。
- 控制器记录区间为`status.data[0]`首末控制器时间之差，包含已记录等待、运行和停车，排除此前配置及预检；它不同于视频判定的任务完成时间。
- 服务端预测与解码不包含相机采集、网络上传和完整HTTP往返；保存的候选可能未被执行。
- 观测到候选就绪为`packet.ready_monotonic - observation_monotonic`，包含输入时龄、传输、推理与落盘，排除后续接入执行等待。
- 日志筛选要求正式execute记录完成任务序列且grasp/release成功。机器序列完成与物体实际抓起、放入目标盒内分别判断，最终任务成功率来自现场计数。
